⚡ Neon Force

Landing page futurista desenvolvida com HTML, CSS e JavaScript, inspirada no universo gamer e cyberpunk.

🚀 Sobre o Projeto

O Neon Force é um projeto Front-End criado com foco em design moderno, responsividade e interatividade.

O site apresenta uma interface visual inspirada em setups gamers futuristas, utilizando efeitos neon, cores vibrantes e uma experiência mais imersiva para o usuário.

O projeto conta com:

Página inicial estilizada
Seção de produtos em destaque
Página sobre
Página de contato
Layout responsivo
Interações com JavaScript
🎮 Funcionalidades

✅ Landing page moderna
